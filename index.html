    这是什么 & 怎么用

    本工具是默认离线考研助手：把你的目标、计划、师资、复盘方法论和每日打卡集中在一处，纯本地运行，不联网也能用；如需手机与电脑数据互通，可在本页底部开启「☁️ 云同步」。
    左侧导航切换模块（手机窄屏会收成图标栏，点图标即可）。所有数据存在你本机浏览器里，不上传。
    重要：培训期网络不稳，每周日务必在「数据」页导出一次 JSON 备份；换设备、清缓存前也导出。

    🏠 今日

    功能：顶部双倒计时（距初试 12/19、距启动 8/1）；按你当前阶段（启动周 / 培训工作日 / 周末 / 冲刺 / 考试 / 已结束）自动派发当日任务清单；记录今日学时并对比目标。
    操作：① 逐项勾选已完成任务，勾选即时保存（绿色删除线表示完成）。② 记学时两种方式：填数字（如 5.5）走「今日学时」框；或点「开始学习」计时器，学完点「结束」自动把真实时长写进今日学时（也支持暂停/继续，刷新页面不丢）。系统对比当日目标并提示是否达标。③ 8/1 前显示「启动周预览」，先照着准备。

    🗺️ 计划

    功能：全程 10 个阶段时间轴（P1 启动周 → 考试）；培训期工作日 / 周末 / 全天冲刺三套时段模板；启动周 8/1–8/6 逐日拆解。国庆标注「待定兜底」。
    操作：这是参照模板，不用打卡。照着对应阶段 / 模板推进；任务重排或砍量以你的实际时间为准（工作日只有 5 小时碎片）。

    📚 科目

    功能：四科八项师资映射（数学高数/线代/概率、英语一/作文、802 信号/通信、政治），含关键提醒（二重积分听武忠祥、kira 概率不换、政治 10/1 才开）。
    操作：纯查阅。按老师推进，不要中途换老师（沉没成本最高）。基础薄弱 + 不死磕偏怪难题，遇到偏/怪题直接跳过。

    🔁 复盘

    功能：你的复盘方法论原文（英语阅读/作文、专业课、政治、日/周/月复盘，一字未改）；「复盘容易踩的坑」五条原文；「本周复盘」表单（按你的框架，本地保存）。
    操作：每周填一次「本周复盘」四个空（效率低那天 / 需加强科目 / 可稍放科目 / 看见的进步），点「保存本周复盘」即存本机，按月可回看。合上本子能讲出「考什么、为什么错、下次怎么避免」才是真复盘。

    📋 档案

    功能：固定档案七节（目标 / 战略定位 / 时间约束 / 师资 / 基础水平 / 复盘规划 / 待补充）+ 回答规范。等于把那份提示词装进口袋，离线可查。
    操作：纯查阅。需要确认某个事实（802 范围、时间节点、国庆待定）时翻这里。

    📊 数据

    功能：近 14 天学时柱状图（合计/日均）；本月打卡日历（今天、考试日高亮，有打卡的日期显示绿点）；JSON 导出 / 导入。
    操作：① 看学时曲线和日历了解节奏。② 点「导出 JSON」下载备份到本机；点「导入 JSON」选之前的备份文件即可恢复（换手机 / 清缓存后用）。每周日务必导出一次。

    💡 通用操作贴士

    ☁️ 云同步（手机↔电脑 数据互通）

    把备考数据存到你的 GitHub 私有 Gist，多台设备填同一个 Token 即自动同步。同步内容不含 AI Key，Token 仅存本机。建议用 https 线上版开启（本地双击 file:// 版可能被浏览器 CORS 拦截）。
    未初始化
    首次：用一台设备点「初始化云端」创建私有仓库；其他设备点「从云端拉取」即可对齐。之后任一边改动会自动上传覆盖，最后操作的设备为准。
